# 01 - 系统设计

> 实验室危化品库房环境智能管控系统 —— 系统架构与软件模块设计

## 1. 设计目标

危化品库房安全风险主要来源于：

1. **易燃/有毒气体泄漏**（如煤气、烟雾、甲醛）
2. **液体泄漏积水**（试剂瓶破损、水管渗漏）
3. **温湿度异常**（高温、高湿加速试剂变质）
4. **无关人员进入**（门禁管理缺失）

本系统围绕"**监测 → 判断 → 报警 → 联动控制**"设计闭环：

- **监测**：MQ-2、DHT11、21VOC、ADC 水位传感器实时采集
- **判断**：主程序按阈值与状态机判断是否触发报警
- **报警**：蜂鸣器鸣叫、红色 LED 闪烁、LCD 界面标红
- **联动**：继电器自动断电/开阀/开风机，门禁受 RFID 白名单控制

## 3. 模块划分

### 3.1 C 版（`app/`）

| 模块 | 职责 | 关键接口 |
|------|------|----------|
| `main.c` | 主控：UI 布局、主循环、状态机 | `main()`, `process_rfid()`, `process_sensors()`, `check_alarm()` |
| `ui_lcd` | LCD 显示驱动 | `lcd_draw_string()`, `lcd_fill_rect()`, `lcd_draw_rect()` |
| `rfid_card` | RFID 读卡 + 白名单 | `rfid_read_card()`, `rfid_verify_card()` |
| `gas_monitor` | MQ-2 气体读取 | `gas_read()` → 0 正常 / 1 报警 |
| `weather` | DHT11 温湿度 | `weather_read(&temp, &hum)` |
| `water_sensor` | ADC 水位检测 | `water_read()` → 原始值, 阈值 800 |
| `alarm` | 声光报警 + 继电器 | `alarm_activate()`, `alarm_relay_on()`, `alarm_indicate_door_open()` |

**C 版主循环（简化）：**

```c
while (running) {
    process_rfid();      // 刷卡检测 → 授权开门 / 拒绝闪红灯
    process_sensors();   // 气体 / 水位每周期轮询, DHT11 每 3 秒
    check_alarm();       // 任一报警源触发 → 声光报警
    update_status_display(...);  // UI 刷新
    update_data_display(...);
    usleep(100000);      // 100ms 周期 (10Hz)
}
```

### 3.2 Qt 版（`app_qt/`）

Qt 版采用 **信号/槽** 架构，`HardwareManager` 作为硬件核心，通过信号通知界面更新，界面与硬件完全解耦：

| 模块 | 职责 | 关键接口 |
|------|------|----------|
| `mainwindow` | 主界面与 UI 刷新 | 槽函数 `onSensorUpdate()` / `onCardDetected()` / `onAlarmChanged()` |
| `hardwaremanager` | 10Hz 轮询、状态聚合 | `poll()`, `init()`, `shutdown()` |
| `gasmonitor` | MQ-2 气体 | `gas_read()` |
| `weather` | DHT11 温湿度 | `weather_read()` |
| `voc21sensor` | 21VOC 帧解析（HCHO/CO₂） | `voc21_read(&hcho, &co2)` |
| `rfidcard` | RFID 刷卡 | `rfid_read_card()`, `rfid_verify_card()` |
| `alarm` | 蜂鸣器 / LED / 继电器 | `alarm_activate()`, `alarm_relay_on()` |

**Qt 版数据流：**

```
QTimer (100ms)
   └─▶ HardwareManager::poll()
         ├─▶ pollSensors()  ── 组装 SensorData
         │       └─ signal sensorUpdated(data)
         │             └─▶ MainWindow::onSensorUpdate() → 更新 QLabel
         ├─▶ pollRfid()
         │       └─ signal cardDetected(id, granted)
         │             └─▶ MainWindow::onCardDetected() → 更新刷卡栏/门禁状态
         └─▶ checkAlarm()
                 └─ signal alarmChanged(active)
                       └─▶ MainWindow::onAlarmChanged() → 报警横幅样式切换
```

## 4. 报警逻辑设计

### 4.1 C 版报警条件

| 报警源 | 触发条件 | 响应动作 |
|--------|----------|----------|
| 气体泄漏 (MQ-2) | 传感器输出为报警态 | 蜂鸣器 + 红灯 + 继电器联动 |
| 积水 (ADC) | 原始值 ≥ 800 | 同上 |
| 温湿度 | 仅监测显示，不触发报警 | — |

### 4.2 Qt 版报警条件

| 报警源 | 触发条件 | 阈值 |
|--------|----------|------|
| 气体泄漏 (MQ-2) | `gas_read() == 1` | 硬件判定 |
| 甲醛 (HCHO) | `hcho ≥ HCHO_THRESHOLD` | 0.10 mg/m³ |
| CO₂ | `co2 ≥ CO2_THRESHOLD` | 1000 ppm |

任意报警源触发 → `alarm_activate()`：蜂鸣器鸣叫 + 红色 LED + 界面红色报警横幅；
全部解除 → `alarm_deactivate()` 恢复正常（绿色 LED）。

### 4.3 门禁逻辑

| 事件 | 动作 |
|------|------|
| 授权卡刷卡 | 继电器开门 5 秒后自动关闭；绿色指示灯 |
| 未授权卡刷卡 | 红色 LED 闪 300ms；无蜂鸣；界面显示 REJECTED |
| 连续异常 | 记录刷卡信息于界面信息栏 |

## 6. 关键设计说明

1. **读写失败保持旧值**：传感器读取失败（如 DHT11 偶发错误）时保留上一次有效数据，避免界面闪烁，同时置 `weather_valid = 0` 标记数据陈旧。
2. **报警防抖**：Qt 版通过记录 `m_alarmActive` 状态，仅在状态翻转时执行一次报警开启/关闭动作并发出信号。
3. **非阻塞读卡**：RFID 串口采用 `VMIN=0, VTIME=1`（100ms 超时）非阻塞读取，避免阻塞主循环。
4. **模块解耦**：C 版按外设拆分 .c/.h；Qt 版用信号槽解耦硬件与 UI，`#ifdef SIMULATE_HARDWARE` 实现硬件模拟。

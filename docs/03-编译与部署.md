# 03 - 编译与部署

> 实验室危化品库房环境智能管控系统 —— 编译、部署与运行指南

## 1. 工具链准备

### 1.1 C 版（GEC6818）

需要安装 ARM 交叉编译工具链：

```bash
sudo apt install gcc-arm-linux-gnueabihf
# 或使用厂商提供的交叉编译工具链，确保 arm-linux-gnueabihf-gcc 可用
```

### 1.2 Qt 版

- **ARM（GEC6818）**：安装 Qt 5 for Embedded / 对应交叉编译的 qmake
- **桌面（调试演示）**：安装 Qt 5 开发环境（Windows/macOS/Linux 均可）

## 2. C 版编译（app/）

```bash
cd app
make            # 使用 Makefile 交叉编译
```

Makefile 关键配置：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `CROSS_COMPILE` | `arm-linux-gnueabihf-` | 交叉编译前缀 |
| `TARGET` | `lab_chemical_control` | 生成的可执行文件名 |
| `CFLAGS` | `-O2 -Wall -Wextra` | 编译优化与告警 |
| `LDFLAGS` | `-lm` | 链接数学库 |

常用目标：

```bash
make                 # 编译
make clean           # 删除 .o
make distclean       # 删除 .o 与可执行文件
make info            # 查看交叉编译器信息
make help            # 查看帮助
```

## 3. 部署到 GEC6818

### 3.1 通过 make install

```bash
cd app
make install BOARD_IP=192.168.1.100
# 等价于: scp lab_chemical_control root@192.168.1.100:/root/
```

### 3.2 手动部署

```bash
scp app/lab_chemical_control root@192.168.1.100:/root/
ssh root@192.168.1.100
chmod +x /root/lab_chemical_control
./lab_chemical_control
```

### 3.3 运行与退出

- 运行后系统自动初始化各设备并进入 10Hz 主循环
- `Ctrl+C`（SIGINT）优雅退出，关闭所有外设并还原状态

## 4. Qt 版编译

### 4.1 桌面模拟模式（推荐先体验）

```bash
cd app_qt
qmake CONFIG+=desktop    # 定义 SIMULATE_HARDWARE，使用模拟硬件
make
./lab_chemical_control
```

- 窗口为 800×480，底部多出一排 **调试按钮**（Gas Alarm / HCHO Alarm / Card Grant 等），可模拟各类事件验证界面逻辑。
- `main.cpp` 中若改为 `w.show()`（注释掉 `showFullScreen()`）则以窗口模式显示。

### 4.2 ARM 模式（GEC6818）

```bash
cd app_qt
qmake -spec linux-arm-gnueabihf-g++    # 交叉编译 spec
make
# 部署方式与 C 版相同：scp + 运行
```

`lab_chemical_control.pro` 关键点：

| 配置 | 说明 |
|------|------|
| `QT += core gui widgets` | 依赖的 Qt 模块 |
| `CONFIG += c++11` | C++11 标准 |
| `desktop { DEFINES += SIMULATE_HARDWARE }` | 桌面模式启用硬件模拟 |
| 默认（非 desktop） | 按真实硬件编译 |

## 5. RFID 卡号采集（rfid_dump.c）

用于将新卡片 UID 加入门禁白名单：

```bash
# 交叉编译
arm-linux-gnueabihf-gcc rfid_dump.c -o rfid_dump

# 部署到板子
scp rfid_dump root@192.168.1.100:/root/
ssh root@192.168.1.100

# 运行，刷卡后终端显示卡号
./rfid_dump
```

输出示例：

```
[#001] HEX: A1B2C3D4  |  ASCII: "A1B2C3D4"
       ^^^ Possible card UID (4 bytes)
       Add this to whitelist[] in rfidcard.c:
       "A1B2C3D4",
```

将输出的十六进制卡号填入白名单数组（`app/rfid_card.c` 或 `app_qt/rfidcard.cpp` 的 `whitelist[]`），重新编译部署即可授权。

## 6. 常见问题排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 编译报找不到 `arm-linux-gnueabihf-gcc` | 未安装交叉工具链 | `apt install gcc-arm-linux-gnueabihf` 或使用厂商工具链 |
| 运行报 `Failed to open /dev/xxx` | 驱动未加载 / 权限不足 | 确认板卡驱动已 insmod；`chmod 666 /dev/xxx` 或以 root 运行 |
| RFID 读不到卡 | 接线错误 / 串口占用 | 检查 UART 接线；`fuser /dev/ttySAC2` 查看占用 |
| DHT11 读数异常 | 数据线无上拉 / 驱动时序 | 加 4.7k~10k 上拉电阻；重新加载驱动 |
| LCD 花屏 | framebuffer 初始化失败 | 确认 `/dev/fb0` 存在，分辨率 800×480 32bpp |
| Qt 版刷不出数据 | 仍为 ARM 模式而硬件未接 | 桌面调试请使用 `qmake CONFIG+=desktop` |

## 7. 一键部署脚本参考

```bash
#!/bin/bash
# build_deploy.sh - 编译并部署到 GEC6818
BOARD_IP=${1:-192.168.1.100}

cd app
make || exit 1
make install BOARD_IP=$BOARD_IP
ssh root@$BOARD_IP "chmod +x /root/lab_chemical_control && /root/lab_chemical_control"
```

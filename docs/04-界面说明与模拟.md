# 04 - 界面说明与模拟

> 实验室危化品库房环境智能管控系统 —— UI 布局、网页预览与桌面模拟调试

## 1. 界面总览

系统界面为 **800×480**，与 GEC6818 LCD 完全一致，自上而下分为 4 个区域：

| 区域 | 高度 | 内容 |
|------|------|------|
| 标题栏 TitleBar | 40px | 系统名称：`Lab Chemical Warehouse Env Control System v1.0`（深蓝底白字） |
| 主区域 MainArea | 390px | 左：系统状态面板（280px）；右：传感器监控面板 |
| 刷卡信息栏 CardInfoBar | 30px | 当前时间 + 最近一次刷卡信息 |
| 状态栏 FooterBar | 20px | 运行时长（Uptime）+ 系统标识 |

## 2. 各区域说明

### 2.1 系统状态面板（左）

| 项目 | 正常显示 | 报警显示 |
|------|----------|----------|
| Gas | `Gas: ✔ Normal`（绿） | `Gas: ALARM! (leak detected)`（红加粗） |
| Toxic/HCHO | `HCHO: ✔ Normal (x.xx)`（绿） | `HCHO: ALARM! (toxic gas detected)`（红加粗） |
| Gate | `Gate: ✔ Locked`（绿） | `Gate: OPEN (access granted)`（青色） |
| 总状态 | `Status: ✔ All Normal`（绿底黑） | `!!! ALARM ACTIVE !!!`（红底白字横幅） |

### 2.2 传感器监控面板（右）

| 项目 | 内容 |
|------|------|
| Temperature | 温度，如 `25.3 ℃`（青色） |
| Humidity | 湿度，如 `60.5 %`（青色） |
| Gas/Smoke | `Clear (Normal)` 或红色报警块 `*** DETECTED ***` |
| Water Level（C 版） | `Normal (ADC: 320)` 或 `*** LEAK DETECTED ***` |
| HCHO（Qt 版） | 甲醛浓度 mg/m³，超标红色报警块 |
| CO2（Qt 版） | 二氧化碳浓度 ppm |

### 2.3 刷卡信息栏

- 无卡：`Card: -- No card read --`（灰色）
- 授权：`Card: A1B2C3D4 [GRANTED]`（绿色加粗）
- 拒绝：`Card: DEADBEEF [REJECTED]`（红色）

## 3. 网页模拟预览（模拟界面预览.html）

无需任何硬件，浏览器直接打开 **`模拟界面预览.html`** 即可查看 800×480 的 UI 模拟，支持交互操作：

| 按钮 | 功能 |
|------|------|
| 触发/解除气体报警 | 模拟 MQ-2 气体泄漏报警，界面状态与横幅实时联动 |
| 触发/解除积水报警 | 模拟 ADC 水位报警（左侧状态 + 右侧数值联动） |
| 刷卡授权 | 模拟授权卡 `A1B2C3D4` 刷卡，门禁 5 秒后自动关闭 |
| 刷卡拒绝 | 模拟未授权卡 `FFFF0000` 刷卡，显示 REJECTED |
| 重置 | 恢复全部传感器与门禁初始状态 |

页面同时模拟温度/湿度/ADC 读数的随机波动与系统时钟、运行时长刷新（500ms 刷新周期，模拟真实 10Hz 系统）。

## 4. Qt 桌面模拟调试（SIMULATE_HARDWARE）

### 4.1 编译运行

```bash
cd app_qt
qmake CONFIG+=desktop
make
./lab_chemical_control
```

### 4.2 调试按钮

启用桌面模式后，界面底部出现一排调试按钮：

| 按钮 | 模拟事件 |
|------|----------|
| `Gas Alarm` | 触发 MQ-2 气体报警 |
| `Gas Clear` | 清除气体报警 |
| `HCHO Alarm` | 模拟甲醛超标（值设为 950 > 阈值 0.10） |
| `HCHO Clear` | 清除甲醛报警（恢复 120） |
| `Card Grant` | 模拟授权卡 `A1B2C3D4` 刷卡（5 秒后自动关门） |
| `Card Reject` | 模拟未授权卡 `DEADBEEF` 刷卡 |
| `Reset All` | 重置所有传感器与门禁状态 |

### 4.3 模拟机制

`HardwareManager` 在 `SIMULATE_HARDWARE` 下：

- 用 `QTimer`（500ms）模拟温度/湿度/甲醛/CO₂ 的随机波动
- 报警状态由调试按钮直接置位，走与真实硬件相同的 `checkAlarm()` 判定与信号通知流程
- UI 刷新路径与 ARM 实机完全一致，可完整验证界面与报警联动逻辑

## 5. C 版实机界面（GEC6818）

C 版（`app/`）通过 Framebuffer 直接绘制同样的 800×480 界面，布局与 Qt 版一致：

- 标题栏：深蓝底（`COLOR_NAVY`）+ 白色标题
- 主区域：黑色底 + 深灰边框面板，左 280px 状态区、右传感器区
- 刷卡栏：深灰底，显示时间与最近卡片信息
- 状态栏：深蓝底，显示运行时长

刷新频率同样为 10Hz（主循环 `usleep(100000)`）。

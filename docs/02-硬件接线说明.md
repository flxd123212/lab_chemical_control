# 02 - 硬件接线说明

> 实验室危化品库房环境智能管控系统 —— GEC6818 平台与传感器接线

## 1. 硬件平台

| 项目 | 规格 |
|------|------|
| 主控板 | GEC6818 开发板（Samsung S5P6818，ARM Cortex-A53 八核） |
| 操作系统 | Linux（嵌入式发行版） |
| 显示屏 | 800×480 32bpp RGB LCD，Framebuffer 驱动 |
| 交叉编译 | `arm-linux-gnueabihf-gcc` |

## 2. 外设总览

| 外设 | 连接接口 | 设备节点 | 备注 |
|------|----------|----------|------|
| RC522 RFID 读卡器 | UART2（RX2/TX2） | `/dev/ttySAC2` | 9600 8N1，C 版 |
| RC522 RFID 读卡器 | UART1（RX1/TX1） | `/dev/ttySAC1` | 9600 8N1，Qt 版 |
| MQ-2 气体传感器 | GPIO | `/dev/gec_gas_drv` | 返回 `'0'` 正常 / `'1'` 报警 |
| DHT11 温湿度 | GPIO | `/dev/humidity` | 返回 4 字节：湿度整数/小数 + 温度整数/小数 |
| 水位传感器 | ADC 通道 2 | `/dev/gec6818_adc` | 0~4095，阈值 800 |
| 21VOC 空气质量 | UART2 | `/dev/ttySAC2` | 9600 8N1，主动上报（Qt 版） |
| 蜂鸣器 | PWM2（GPIO C+14） | `/dev/pwm` | ioctl 设置频率/停止 |
| 红色 LED (D7) | GPIOE13 | `/dev/Led` | ioctl(LED1, 0)=亮, 1=灭 |
| 绿色 LED (D8) | GPIOC17 | `/dev/Led` | ioctl(LED2, 0)=亮, 1=灭 |
| 继电器 | GPIO B+28 | `/dev/relay` | ioctl 控制门锁/气阀/风扇 |

## 3. 传感器接线

### 3.1 RC522 RFID（MFRC522）

```
RC522 模块         GEC6818
─────────          ────────
SDA(SS)    ───────► 片选 GPIO
SCK        ───────► SPI/GPIO 时钟
MOSI       ───────► 主出从入
MISO       ◄─────── 主入从出
RST        ───────► 复位 GPIO
3.3V       ───────► 3.3V 电源
GND        ───────► GND
```

> 本项目经 UART 转接读取卡号（`rfid_dump.c` / `rfid_card.c`），卡号以十六进制字符串输出。

### 3.2 MQ-2 气体传感器

- **供电**：5V
- **信号输出**：接 GPIO 数字输入（板上已接 `/dev/gec_gas_drv` 驱动）
- **说明**：预热 3~5 分钟后读数稳定；传感器输出为数字量，`'0'` 表示正常，`'1'` 表示浓度超标。

### 3.3 DHT11 温湿度传感器

- **供电**：3.3V / 5V
- **数据脚**：接 GPIO（板载 `/dev/humidity` 驱动）
- **通信**：单总线协议，由驱动完成时序；应用层读取 4 字节：`湿度整数, 湿度小数, 温度整数, 温度小数`

### 3.4 水位/积水传感器

- **供电**：3.3V ~ 5V
- **信号**：模拟量 → 板载 ADC 通道 2（`/dev/gec6818_adc`）
- **判定**：`water_read()` 返回 0~4095，**≥ 800** 判定为有水（阈值可在 `water_sensor.h` 中按实际标定调整）

### 3.5 21VOC 五合一空气质量传感器（Qt 版）

- **供电**：5V
- **数据**：UART 主动上报，9600 8N1，每 1~2 秒一帧
- **帧格式**（9 字节）：

```
Byte0  Byte1   Byte2/3        Byte4/5        Byte6/7    Byte8
0xAA   0x15    HCHO_L/H  →   CO2_L/H  →     TVOC_L/H   CS校验
帧头    类型    甲醛(mg/m³)    CO2(ppm)       保留       累加和
```

- 甲醛 = `(HCHO_H<<8 | HCHO_L)` mg/m³；CO₂ = `(CO2_H<<8 | CO2_L)` ppm
- 报警阈值：HCHO ≥ **0.10 mg/m³**，CO₂ ≥ **1000 ppm**（`voc21sensor.h` 可调）
- 若实际传感器协议不同，只需修改 `voc21_parse_frame()` 帧解析逻辑

### 3.6 声光报警与执行器

| 外设 | 控制方式 |
|------|----------|
| 蜂鸣器 | `ioctl(fd, 1, freq)` 开（设置频率），`ioctl(fd, 0, 0)` 关 |
| 红色 LED | `ioctl(fd, LED1, 0)` 亮，`ioctl(fd, LED1, 1)` 灭 |
| 绿色 LED | `ioctl(fd, LED2, 0)` 亮，`ioctl(fd, LED2, 1)` 灭 |
| 继电器 | 开（开门/断电），关（关门/恢复） |

## 4. 接线注意事项

1. **共地**：所有传感器与开发板必须共地，否则读数不稳定。
2. **供电电流**：蜂鸣器、继电器线圈电流较大，建议通过驱动电路（三极管/ULN2003）驱动，勿直接从 GPIO 取电。
3. **DHT11 上拉**：数据线需 4.7kΩ~10kΩ 上拉电阻。
4. **MQ-2 预热**：上电后预热数分钟再投入使用，读取结果才准确。
5. **串口参数统一**：RFID / 21VOC 均为 **9600 8N1**，且需 `O_NOCTTY` 打开，禁用流控与回声。
